# 国科大人工智能专业华大专项报考指南 UX PRD

## 目标

建立一个面向 2027/2028 届计算机考研学生的单页介绍网站，介绍“国科大人工智能学院人工智能专业 · 华大联培”，并以 2026 届考研信息作为历史样本，帮助用户顺序了解项目、培养、报考数据、考试复试和常见疑问。

## 已知信息

- 主题是用户所在研究生院校的报考指南。
- “华大”全称为“中国科学院大学人工智能学院人工智能专业华大专项”。
- 网站服务于正在做择校决策的计算机考研学生，而非覆盖多学院多专业的通用招生站。
- 用户期望内容顺序先介绍华大专项，再展示 26 考研概况。
- 网站的主要读者是 2027/2028 届考研学生；2026 届数据是历史参考，不是对未来招生结果的承诺。
- 这是一个介绍型网站，不需要“加入择校清单”、登录、收藏或其他任务管理功能。
- 全站信息都是“学生整理口径”，不代表中国科学院大学、人工智能学院、华大基因或其他官方机构的立场。
- 全站信息统一标注为“学长自行统计，非官方信息”，包括培养、报考、录取、费用和补助等所有内容。
- 当前优先讨论 UX 逻辑、内容数据与用户 workflow，尚不进入页面实现。
- 已确认采用完整的一页阅读指南，不拆分独立的数据页。
- 已确认不设置“适配性判断”区块，也不设置独立的“数据来源/核验入口”区块。
- Q&A 必须完整展示原文，不作中性化改写；仅添加低干扰的非官方信息提醒。
- 核心 UX 原则是让用户始终知道正在阅读的主题，并能随时通过顶部导航跳转。
- 当前仓库为空，没有既有产品结构或技术约束。

## 暂定假设

- 网站的核心价值是“把一个陌生、具体的联合培养项目讲清楚”。
- 首屏应在很短时间内说清项目全称、专业、学籍证书归属与培养关系，然后按阅读顺序展示其余信息。
- 首期为单院校、单年度的静态介绍页，不提供年份切换或数据查询功能。

## 需求（演进中）

- 首屏需在不依赖用户了解国科大或华大基因的前提下，说清项目全称、所属专业、培养关系与核心特点。
- 用户能从择校问题出发浏览，不需要先理解国科大的组织架构。
- 单页的每个内容区块有清晰标题和连续阅读顺序；顶部导航可跳转至对应区块。
- 关键报考数据以静态可读图表展示，明确区分历史样本与少干计划样本。
- 内容层级围绕用户问题组织，而不是照搬官网栏目。
- 26 届数据需要显示为“历史参考”，避免 27/28 届用户将其误认为当届招生政策。
- 网站以连续阅读与区块跳转为主，不引入账号、个人数据或任务管理 workflow。
- 首屏和页脚都需显示“非官方站点，学生整理，仅供参考，以官方招生文件为准”。
- 每个内容区块以小字标明“学生整理，非官方信息，仅供参考；请以当年官方招生文件为准”。
- 保持原始材料的表达，不对学费、补助、培养体验或经验性判断作中性化改写；提醒语不改变原文含义。

## 验收标准（演进中）

- [ ] 新用户进入首页后，不查阅外部资料也能说清华大专项的所属、培养关系和核心特点。
- [ ] 26 考研概况能集中展示分数分布、录取分数和复试录取样本。
- [ ] 用户在任意区块都能明确当前阅读主题，并可从顶部导航跳至其他主题。
- [ ] 首屏、数据区域、培养与经验区域、Q&A 和页脚均显示这是学生整理的非官方内容。

## 完成标准

- 确定单页阅读顺序、内容边界和数据展示方式。
- 形成信息架构、页面区块清单和关键页面线框。
- 形成可审计的完整 UX 设计文档，并在实现前由用户确认。

## 范围外（当前）

- 未完成 UX 和内容方案前，不选定具体前端技术栈。
- 不在原始材料之外补充、推断或改写招生信息。
- 首期不包含账号系统、社区、在线咨询、收藏、筛选、年份切换或备考任务功能。
